# Vishnu Vardhan — Luxury Portfolio

A cinematic, monochrome personal portfolio built with React, Vite, Three.js / React Three Fiber, Drei and Lenis.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
